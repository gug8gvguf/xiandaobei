# 统一程序接口

## 1. 学生实现哪里

在自己的源码目录中实现 `solution.py`，文件中必须提供名为 `Solution` 的类。题目包中的 `submission/solution.py` 只保留接口骨架，尚未实现推理，不能直接当作已完成作品运行。

`baseline/solution.py` 是单独提供的可运行FP32参考程序。测试学生程序时，不会自动回退到基准，也不会因为基准能运行就视为学生作品完成。

固定入口如下：

```python
class Solution:
    def __init__(self, model_dir: str,
                 tokenizer_path: str,
                 device: str = "cuda:0"):
        # 在这里完成公共模型加载和输入无关的初始化。
        ...

    def generate(self, prefixes: list[str],
                 max_new_tokens: int) -> list[str]:
        # 在这里处理本次输入并返回新生成后缀。
        ...
```

学生可以增加自己的辅助函数、类和源码文件，但不能改动上述入口名称、参数含义和返回格式。

## 2. 参数与返回值

| 名称 | 必须遵守的含义 |
|---|---|
| `model_dir` | 测试程序传入的公共ProGen2-medium权重目录，用它加载公共权重 |
| `tokenizer_path` | 测试程序传入的统一Tokenizer文件路径 |
| `device` | 测试指定设备；DCU版PyTorch仍使用 `cuda:0` 名称 |
| `prefixes` | 输入前缀列表，列表长度就是本次Batch Size |
| `max_new_tokens` | 每条输入必须继续生成的新氨基酸字母数 |
| 返回值 | `list[str]`，仅含新生成后缀，条数和顺序与输入一一对应 |

例如输入有8条前缀，`max_new_tokens=256`，就必须返回8个字符串，每个恰好256个字母。**返回值不包含原输入前缀**，也不包含FASTA标题、空格或换行。

输出只允许下面20种大写标准氨基酸字母：

```text
ACDEFGHIKLMNPQRSTVWY
```

输入开头的 `1` 或 `2` 是ProGen控制标记，必须原样保留并参与模型输入；不能删去或替换。控制标记不是返回后缀中的氨基酸字母。

## 3. 同一套程序处理四项测试任务

测试程序创建 `Solution` 后，通过同一 `generate()` 接口依次提供以下任务：

| 测试任务 | `len(prefixes)` | 每条前缀Token长度 | `max_new_tokens` | 返回要求 |
|---|---:|---:|---:|---|
| 1 单条生成 | 1 | 32 | 256 | 1条，每条256个新字母 |
| 2 多条生成 | 8 | 32 | 256 | 8条，每条256个新字母 |
| 3 生成较长 | 4 | 32 | 512 | 4条，每条512个新字母 |
| 4 输入较长 | 4 | 512 | 64 | 4条，每条64个新字母 |

前缀长度按统一Tokenizer编码后的Token数计算，不能直接当作Python字符串长度。同一次调用内各条前缀Token长度相同，但内容不同。

内部可以按需要合批、分批或调度，计时覆盖生成并返回全部规定结果的过程。不能更改输入任务数、生成长度、输入顺序或只处理其中一部分。

## 4. 生成规则

每一步读取最后位置的Logits，仅在20种标准氨基酸对应的Token中选择最高分；并列时按 `ACDEFGHIKLMNPQRSTVWY` 的固定顺序选择第一个。采用确定性贪心生成，固定生成规定长度。

不得随机采样，不得用temperature、top-k、top-p改变候选选择，也不得因EOS或其他控制Token提前结束。`config.json` 中保留的上游采样默认值不能代替本题规则。

## 5. 请求之间的状态

每次 `generate()` 必须独立计算本次输入。不能复用上一请求的生成结果或输入相关KV Cache，也不能依赖测试调用次数返回预存结果。

可以保留公共模型、已编译算子、与输入内容无关的RoPE表、预分配缓冲区容量等通用资源。复用缓冲区时，必须清除或覆盖上一请求的有效输入相关内容，不能把旧数据当作新输入计算结果。

`reset()` 是可选方法。如果实现，测试器会在每次预热或生成调用前执行它，用于清除请求状态。即使没有 `reset()`，`generate()` 本身也必须保证请求独立。`reset()` 不接收本次输入，不能用于提前完成本次任务。

## 6. 文件导入与构建

可以在作品目录中增加 `src/`、`ops/` 或 `models/` 等自有源码目录，并由 `solution.py` 导入。不得写死个人账号、机器绝对路径、权重位置或设备编号；模型、Tokenizer和设备必须使用传入参数。

如需C++/HIP扩展，可提供 `build.sh`，在推理计时前离线构建一次。计时生成期间不能安装依赖、联网下载或临时编译。实际使用的额外依赖和构建条件须在报告的“运行说明”中说明，并按比赛要求提前确认。
